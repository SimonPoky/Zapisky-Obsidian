# diskrétní graf

> [!lidsky] Lidsky
> Graf bez jediné hrany, jen samostatné tečky. Je bipartitní, protože žádná hrana nic neporušuje.
>
> *Příklad:* D₃ = ({1, 2, 3}, ∅); jednovrcholový graf ({1}, ∅) je D₁.

**Formálně:** Dₙ = (V, ∅), |V| = n; |E| = 0
