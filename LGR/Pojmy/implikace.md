# implikace

> [!lidsky] Lidsky
> Slib „jestliže α, pak β“. Nepravdivý je jen tehdy, když α platí a β ne; při nepravdivém předpokladu je implikace pravdivá vždy.

**Formálně:** u(α ⇒ β) = 0 ⇔ u(α) = 1 a u(β) = 0; α ⇒ β |=| ¬α ∨ β
