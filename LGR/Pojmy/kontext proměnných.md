# kontext proměnných

> [!lidsky] Lidsky
> Tabulka dosazení: ke každé proměnné říká, za který prvek universa právě stojí. Bez ní nejde rozhodnout, jestli platí formule s volnými proměnnými, např. x < 0.
>
> *Příklad:* ρ: x ↦ 7, y ↦ 15, z ↦ 3 na universu ℕ. Při něm je x < 0 nepravdivá (7 < 0), x < x + 1 pravdivá (7 < 8).

**Formálně:** Buď (U, ⟦−⟧) interpretace. Kontext proměnných je zobrazení ρ : Var → U.
