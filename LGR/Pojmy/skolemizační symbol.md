# skolemizační symbol

> [!lidsky] Lidsky
> Nový (fresh) konstantní nebo funkční symbol, který při skolemizaci nahradí existenčně vázanou proměnnou. Musí být nový, aby ho interpretace směla vyložit libovolně, tedy jako svědka; skolemizace tím obohacuje jazyk.
>
> *Příklad:* Nahradit ∃x P(x) za P(a) se starým a nejde: {∃x P(x), ¬P(a)} je splnitelná (U = {0, 1}, ⟦P⟧ = {0}, ⟦a⟧ = 1), ale {P(a), ¬P(a)} ne. S novým c stačí dát ⟦c⟧ = 0.

**Formálně:** skolemizační konstanta c pro ∃ bez ∀ před sebou; skolemizační funkční symbol f arity n pro ∃ za n obecnými kvantifikátory; pro každou proměnnou i každou sentenci jiný nový symbol
