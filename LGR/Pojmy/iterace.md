# iterace

> [!lidsky] Lidsky
> Opsání už dokázané formule o kus níž, i dovnitř vnořeného boxu. Hodí se, když box musí skončit formulí, kterou už máš.
>
> *Příklad:* odvození b ⊢ a ⇒ b: 1. b (P); box: 2. a (P), 3. b (it 1); 4. a ⇒ b (⇒i 2–3). Box musí končit formulí b, proto se b zopakuje.

**Formálně:** φ / φ: formuli z dřívějšího řádku (z otevřeného boxu nebo globální úrovně) smíš zopakovat, odůvodnění „it k“
