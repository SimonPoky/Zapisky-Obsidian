# predikátový symbol

> [!lidsky] Lidsky
> Jméno vlastnosti nebo vztahu: S(x) „x je sudé“, P(x, y) „x je menší než y“. S termy dosazenými na místa argumentů dá tvrzení, které platí, nebo ne.

**Formálně:** P ∈ Pred s aritou n ≥ 0; P(t₁, …, tₙ) je atomická formule; v interpretaci ⟦P⟧ ⊆ Uⁿ (pro n = 0 hodnota 0/1)
