# tautologie predikátové logiky

> [!lidsky] Lidsky
> Sentence pravdivá v každé interpretaci, ať symboly vyložíš jakkoli. Že tautologie není, ukáže jeden nemodel; že je, se musí dokázat obecnou úvahou.
>
> *Příklad:* ∀x (x = x) je tautologie (rovnítko je vždy rovnost, d = d). ∀x (0 · x = 0) tautologie není: v U = {a, b} s ⟦0⟧ = a, a * b = b je pro x := b nepravdivá.

**Formálně:** sentence φ je tautologie ⟺ φ je pravdivá v každé interpretaci (každá interpretace je model φ)
