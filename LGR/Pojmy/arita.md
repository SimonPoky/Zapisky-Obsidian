# arita

> [!lidsky] Lidsky
> Počet argumentů symbolu: S(x) „x je sudé“ má aritu 1, P(x, y) „x < y“ aritu 2.

**Formálně:** ar(P) = n pro predikátový symbol P(t₁, …, tₙ), n ≥ 0; ar(f) = n > 0 pro funkční symbol
