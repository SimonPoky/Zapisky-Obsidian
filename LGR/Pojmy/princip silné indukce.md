# princip silné indukce

> [!lidsky] Lidsky
> Jako slabá indukce, ale v kroku smíš použít všechna předchozí čísla, ne jen to poslední.
>
> *Příklad:* každé n ≥ 2 je součin prvočísel. Je-li n + 1 prvočíslo, hotovo; jinak n + 1 = a·b s 2 ≤ a, b ≤ n, a pro a i b to platí podle předpokladu. Krok potřebuje a, b, ne jen n.

**Formálně:** V vlastnost čísel n ≥ n₀: V(n₀) a (∀ n ≥ n₀: [V(k) pro všechna n₀ ≤ k ≤ n] ⇒ V(n + 1)) ⇒ ∀ n ≥ n₀: V(n); na ℕ ekvivalentní se slabou indukcí a s principem dobrého uspořádání
