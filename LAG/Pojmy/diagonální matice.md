# diagonální matice

> [!lidsky] Lidsky
> Čtvercová matice, která má mimo hlavní diagonálu samé nuly. Jen natahuje osy, každou svým číslem, a proto se s ní počítá po prvcích: součin, mocnina, inverze i polynom.
>
> *Příklad:* A = diag(2, −1, 3): A² = diag(4, 1, 9), A¹⁰ = diag(1024, 1, 59 049), A⁻¹ = diag(1/2, −1, 1/3). (1 1; 0 1) diagonální není.

**Formálně:** Matice A ∈ 𝔽ⁿˣⁿ je diagonální, jestliže aᵢⱼ = 0 pro i ≠ j; značíme A = diag(a₁₁, …, aₙₙ). Pak diag(aᵢ) · diag(bᵢ) = diag(aᵢbᵢ), diag(aᵢ)^k = diag(aᵢ^k)
