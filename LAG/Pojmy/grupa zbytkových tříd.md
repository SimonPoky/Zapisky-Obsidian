# grupa zbytkových tříd

> [!lidsky] Lidsky
> Zbytkové třídy se sčítají přes zástupce, [i] + [j] = [i + j]. Takhle počítají hodiny (n = 12): 9 h + 5 h = 2 h. Je to abelovská grupa s nulou [0] a opačným prvkem [−i].
>
> *Příklad:* v ℤ₁₂ je [9] + [5] = [14] = [2] a −[5] = [7]; v ℤ₂ je [1] + [1] = [0] (liché + liché = sudé).

**Formálně:** Pro n ∈ ℕ je ℤₙ = {[0], [1], …, [n − 1]} se sčítáním A + B = {a + b | a ∈ A, b ∈ B}, tedy [i] + [j] = [i + j]. (ℤₙ, +) je abelovská grupa, neutrální prvek [0] = nℤ, opačný prvek −[i] = [−i]
