# dimenze

> [!lidsky] Lidsky
> Počet nezávislých směrů prostoru = počet prvků libovolné jeho báze (všechny mají stejně, věta 4.7). Přímka 1, rovina 2, 𝔽ⁿ má n, polynomy stupně ≤ n mají n + 1, všechny polynomy ∞.

**Formálně:** Buď L lineární prostor. dim L = počet prvků nějaké (libovolné) báze L; dim {0} = 0 (báze je prázdná posloupnost); nemá-li L žádnou konečnou bázi, dim L = ∞
