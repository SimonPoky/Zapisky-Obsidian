# matice soustavy

> [!lidsky] Lidsky
> Soustava lineárních rovnic zapsaná jako jedna rovnice Ax = b: v A jsou koeficienty, x jsou neznámé, b pravé strany. Řešit soustavu = hledat vzor b.
>
> *Příklad:* x − y + 2z = 3, 2x + y = 0 má matici soustavy $\begin{pmatrix}1&-1&2\\2&1&0\end{pmatrix}$, sloupec neznámých (x; y; z) a sloupec pravých stran (3; 0).

**Formálně:** Soustava m lineárních rovnic o n neznámých aᵢ₁x₁ + … + aᵢₙxₙ = bᵢ (i = 1, …, m) je ekvivalentní rovnici Ax = b, kde A = (aᵢⱼ) ∈ 𝔽^{m×n} je matice soustavy, x ∈ 𝔽ⁿ sloupec neznámých a b ∈ 𝔽ᵐ sloupec pravých stran
