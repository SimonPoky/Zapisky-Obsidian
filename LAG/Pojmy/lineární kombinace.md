# lineární kombinace

> [!lidsky] Lidsky
> Recept „vezmi α₁ krát první vektor, α₂ krát druhý… a všechno sečti“. Čísla αᵢ jsou dávky jednotlivých ingrediencí, říká se jim koeficienty.
>
> *Příklad:* 2·(1; 0) + 3·(0; 1) = (2; 3) je lineární kombinace vektorů (1; 0) a (0; 1) s koeficienty 2 a 3. U polynomů: 5·1 − 2·x + 1·x² = 5 − 2x + x².

**Formálně:** α₁x₁ + α₂x₂ + … + αₙxₙ, kde x₁, …, xₙ ∈ L, α₁, …, αₙ ∈ 𝔽, n ∈ ℕ₀
