# geometrický význam determinantu

> [!lidsky] Lidsky
> |det A| je obsah (ve 3D objem) útvaru ze sloupců A, tedy kolikrát zobrazení x⃗ ↦ Ax⃗ zvětší každý obsah. Záporné znaménko znamená převrácení orientace (jako zrcadlo), nula zplacatění.
>
> *Příklad:* A = (2 1; 1 3), det A = 5: jednotkový čtverec → rovnoběžník o obsahu 5, kruh o obsahu π → elipsa o obsahu 5π. Zrcadlení (1 0; 0 −1) má det = −1.

**Formálně:** A ∈ ℝ²ˣ² (ℝ³ˣ³): |det A| = obsah (objem) rovnoběžníku (rovnoběžnostěnu) ze sloupců A; det A > 0 ⟺ x⃗ ↦ Ax⃗ zachovává orientaci, det A < 0 ⟺ převrací; pro (a b; 0 c) je obsah ac = základna · výška
