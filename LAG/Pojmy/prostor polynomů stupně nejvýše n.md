# prostor polynomů stupně nejvýše n

> [!lidsky] Lidsky
> Všechny polynomy, ve kterých není mocnina vyšší než xⁿ. Sečtením ani vynásobením číslem stupeň nevyroste, takže je to podprostor všech polynomů. Má dimenzi n + 1 (bázi 1, x, …, xⁿ).

**Formálně:** 𝔽≤ⁿ[x] = {α₀ + α₁x + … + αₙxⁿ | αᵢ ∈ 𝔽} = span{1, x, …, xⁿ} ≤ 𝔽[x]
