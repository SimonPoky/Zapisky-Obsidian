# Binetův vzorec

> [!lidsky] Lidsky
> Explicitní vzorec pro n-té Fibonacciho číslo bez počítání předchozích: rozdíl n-tých mocnin dvou kořenů φ₊, φ₋ vydělený √5. Druhý člen je menší než 1/2, stačí zaokrouhlit φ₊ⁿ/√5.
>
> *Příklad:* a₁₀ = [φ₊¹⁰/√5] = [55,004] = 55; a₅ = [4,960] = 5.

**Formálně:** a₀ = 0, a₁ = 1, a_{n+2} = a_{n+1} + aₙ ⇒ aₙ = (1/√5)(φ₊ⁿ − φ₋ⁿ) = [φ₊ⁿ/√5] (zaokrouhlení na nejbližší celé číslo), φ± = (1 ± √5)/2
