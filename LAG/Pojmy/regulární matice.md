# regulární matice

> [!lidsky] Lidsky
> Čtvercová matice, jejíž zobrazení x ↦ Ax je bijekce 𝔽ⁿ → 𝔽ⁿ. Právě taková matice má inverzní matici. Nemá-li ji, říká se jí singulární.
>
> *Příklad:* $\begin{pmatrix}1&2\\3&4\end{pmatrix}$ je regulární, sloupce jsou LN a inverze je $\begin{pmatrix}-2&1\\3/2&-1/2\end{pmatrix}$. $\begin{pmatrix}1&2\\2&4\end{pmatrix}$ je singulární: (2; −1) jde na (0; 0).

**Formálně:** Matice A ∈ 𝔽^{n×n} je regulární ⟺ zobrazení 𝔽ⁿ → 𝔽ⁿ, x ↦ Ax je izomorfismus (na cvičení ekvivalentně: existuje A⁻¹ s AA⁻¹ = A⁻¹A = Eₙ)
