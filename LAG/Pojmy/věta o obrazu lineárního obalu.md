# věta o obrazu lineárního obalu

> [!lidsky] Lidsky
> Obraz obalu je obal obrazů: stačí zobrazit generátory. U matice je obraz obal jejích sloupců, protože sloupce jsou obrazy kanonické báze.
>
> *Příklad:* im $\begin{pmatrix}1&2&-1\\2&4&-2\\1&3&0\end{pmatrix}$ = span{(1; 2; 1), (2; 4; 3), (−1; −2; 0)} = span{(1; 2; 1), (2; 4; 3)}. U derivace na ℝ^{≤3}[x]: im D = span{0, 1, 2x, 3x²} = ℝ^{≤2}[x].

**Formálně:** A ∈ Lin(V, W), x₁, …, xₙ ∈ V ⇒ A(span{x₁, …, xₙ}) = span{Ax₁, …, Axₙ}; pro A = (a₁ ⋯ aₙ) ∈ 𝔽^{m×n} je im A = span{a₁, …, aₙ} ≤ 𝔽ᵐ
