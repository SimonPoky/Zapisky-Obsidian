# věta o zachování lineárních kombinací

> [!lidsky] Lidsky
> Obraz směsi je stejná směs obrazů: kdo ví, kam jdou x₁, …, xₙ, ví, kam jde každá jejich lineární kombinace.

**Formálně:** A: V → W je lineární ⟺ pro všechna n ∈ ℕ₀, α₁, …, αₙ ∈ 𝔽, x₁, …, xₙ ∈ V: A(α₁x₁ + … + αₙxₙ) = α₁Ax₁ + … + αₙAxₙ
