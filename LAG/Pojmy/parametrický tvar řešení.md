# parametrický tvar řešení

> [!lidsky] Lidsky
> Zápis všech řešení soustavy, kde je každá neznámá výraz v parametrech t, s, …; parametrů je tolik, kolik je dimenze řešení homogenní soustavy.
>
> *Příklad:* x − y + 2z = 3 má řešení x = 3 + t − 2s, y = t, z = s (t, s ∈ ℝ), totéž jako (3; 0; 0) + span{(1; 1; 0), (−2; 0; 1)}. Volba t = s = 1 dá řešení (2; 1; 1).

**Formálně:** S = xₚ + span{v₁, …, v_k} zapsané po složkách: x = xₚ + t₁v₁ + … + t_kv_k, t₁, …, t_k ∈ 𝔽, kde k = dim S₀ = n − rank A
