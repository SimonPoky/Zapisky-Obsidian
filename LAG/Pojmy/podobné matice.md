# podobné matice

> [!lidsky] Lidsky
> Dvě matice téhož operátoru v různých bázích: jedna vznikne z druhé přepočtem B = T⁻¹AT přes regulární matici T.
>
> *Příklad:* A = (3 0; 1 2), T = (0 1; 1 1): T⁻¹AT = diag(2, 3), takže A je podobná diag(2, 3). Matice 2E₂ je podobná jen sama sobě, T⁻¹(2E)T = 2E.

**Formálně:** Matice A, B ∈ 𝔽ⁿˣⁿ se nazývají podobné, jestliže existuje regulární matice T ∈ 𝔽ⁿˣⁿ taková, že B = T⁻¹AT
