# cílová množina

> [!lidsky] Lidsky
> Množina B v zápisu f: A → B, do které zobrazení míří. Je součástí zadání a nemusí být zasažena celá; zasaženou část tvoří obor hodnot.
>
> *Příklad:* x² : ℝ → ℝ má cílovou množinu ℝ, ale obor hodnot jen [0; +∞), takže není na. Tentýž předpis s cílovou množinou [0; +∞) už na je.

**Formálně:** pro f: A → B je B cílová množina: f(x) ∈ B pro každé x ∈ A; obecně f(A) ⊆ B, rovnost nemusí platit
