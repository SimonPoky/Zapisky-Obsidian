# Kroneckerovo delta

> [!lidsky] Lidsky
> Zkratka „1, když se indexy rovnají, jinak 0“. Není to matice konkrétního rozměru, jen symbol; v sumě vybere jediný člen.
>
> *Příklad:* δ₂₂ = 1, δ₂₃ = 0 a a₁δ₁₂ + a₂δ₂₂ + a₃δ₃₂ = a₂: ze tří členů zbude jen ten se shodnými indexy.

**Formálně:** δᵢⱼ = 1 pro i = j, δᵢⱼ = 0 pro i ≠ j; např. [Eₙ]ᵢⱼ = δᵢⱼ a Σₖ aᵢₖ δₖⱼ = aᵢⱼ
