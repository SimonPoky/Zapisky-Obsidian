# asociativita skládání zobrazení

> [!lidsky] Lidsky
> U tří zobrazení za sebou nezáleží na závorkách: vektor stejně projde A, pak B, pak C. Proto se píše jen CBA.
>
> *Příklad:* na ℝ: A(x) = 2x, B(x) = x + 1, C(x) = x². Pak C(B(A(3))) = C(B(6)) = C(7) = 49, ať závorkuješ (CB)A, nebo C(BA).

**Formálně:** A: U → V, B: V → W, C: W → Z (libovolná zobrazení) ⇒ C(BA) = (CB)A
