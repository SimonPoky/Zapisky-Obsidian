# vlastní číslo

> [!lidsky] Lidsky
> Číslo λ, kterým operátor některý nenulový vektor jen vynásobí: Ax = λx. Udává, kolikrát se ten směr natáhne (záporné λ ho navíc převrátí, nula ho vynuluje).
>
> *Příklad:* pro A = (3 0; 1 2) je A(1; 1) = (3; 3) = 3 · (1; 1), takže 3 je vlastní číslo; druhé je 2 s vektorem (0; 1). Číslo 5 vlastní není, A − 5E je regulární.

**Formálně:** Buď L lineární prostor nad 𝔽, A ∈ Lin(L). Skalár λ ∈ 𝔽 je vlastní číslo operátoru A, jestliže existuje x ∈ L, x ≠ 0, takový, že Ax = λx. Pro matici A ∈ 𝔽ⁿˣⁿ: λ je vlastní číslo, jestliže Ax = λx pro nějaké x ∈ 𝔽ⁿ, x ≠ 0
