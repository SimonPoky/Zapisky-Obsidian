# triviální lineární kombinace

> [!lidsky] Lidsky
> Kombinace „od všeho nula dávek“. Dá vždy nulový vektor. Nulu ale umí dát i netriviální kombinace, např. 1·x + (−1)·x.

**Formálně:** α₁x₁ + … + αₙxₙ s α₁ = … = αₙ = 0
