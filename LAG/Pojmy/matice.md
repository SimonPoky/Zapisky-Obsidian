# matice

> [!lidsky] Lidsky
> Tabulka čísel s m řádky a n sloupci. Pro sčítání je to jen sloupec m·n čísel poskládaný do obdélníku.
>
> *Příklad:* $\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$ je matice 2 × 3 (2 řádky, 3 sloupce) a a₂₃ = 6. Sčítá se po složkách: $\begin{pmatrix}1&0\\0&1\end{pmatrix}$ + $\begin{pmatrix}2&3\\4&5\end{pmatrix}$ = $\begin{pmatrix}3&3\\4&6\end{pmatrix}$.

**Formálně:** matice typu m × n nad 𝔽 je obdélníkové schéma čísel aᵢⱼ ∈ 𝔽 (i = 1, …, m řádek, j = 1, …, n sloupec); množina všech takových matic je 𝔽^{m×n}, sčítání a násobení skalárem po složkách: [A + B]ᵢⱼ = aᵢⱼ + bᵢⱼ, [αA]ᵢⱼ = αaᵢⱼ
