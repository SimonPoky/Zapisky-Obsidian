# zpětná substituce

> [!lidsky] Lidsky
> Řešení stupňovité soustavy od konce: z poslední rovnice spočítáš poslední hlavní neznámou a výsledky postupně dosazuješ do rovnic nad ní.
>
> *Příklad:* x − y + 2z = 3, 3y − z = −1, 2z = 2: z = 1, pak 3y − 1 = −1 dá y = 0, pak x − 0 + 2 = 3 dá x = 1.

**Formálně:** Pro soustavu s maticí v horním stupňovitém tvaru: zvol volné neznámé, z i-té rovnice (i = r, r − 1, …, 1) vyjádři neznámou x_{k_i} pomocí již známých hodnot
