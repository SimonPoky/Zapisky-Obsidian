# součin matice a vektoru

> [!lidsky] Lidsky
> Matice krát vektor = lineární kombinace sloupců matice, koeficienty jsou složky vektoru. Vektor má tolik složek, kolik má matice sloupců.

**Formálně:** (a₁ ⋯ aₙ) ∈ 𝔽^{m×n}, x = (x₁; …; xₙ) ∈ 𝔽ⁿ ⇒ (a₁ ⋯ aₙ)x = x₁a₁ + … + xₙaₙ ∈ 𝔽ᵐ
