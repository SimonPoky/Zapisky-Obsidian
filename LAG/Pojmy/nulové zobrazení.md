# nulové zobrazení

> [!lidsky] Lidsky
> „Černá díra“: každý vektor pošle do nuly. Je lineární.
>
> *Příklad:* O: ℝ² → ℝ³, O(5; −1) = (0; 0; 0); jeho matice je nulová matice 3 × 2.

**Formálně:** O: V → W, O(x) = o pro všechna x ∈ V; O ∈ Lin(V, W)
