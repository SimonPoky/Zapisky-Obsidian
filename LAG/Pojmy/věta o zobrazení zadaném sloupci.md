# věta o zobrazení zadaném sloupci

> [!lidsky] Lidsky
> Zvol n vektorů a₁, …, aₙ. Zobrazení, které ze sloupce čísel udělá kombinaci x₁a₁ + … + xₙaₙ, je vždy lineární; je to násobení maticí se sloupci aᵢ.

**Formálně:** a₁, …, aₙ ∈ 𝔽ᵐ ⇒ A: 𝔽ⁿ → 𝔽ᵐ, A(x₁; …; xₙ) = x₁a₁ + … + xₙaₙ je lineární
