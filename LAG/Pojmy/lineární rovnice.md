# lineární rovnice

> [!lidsky] Lidsky
> Úloha „kolikrát musím vzít a, abych dostal b“. Když a ≠ 0, je odpověď jediná: b/a.

> [!obrazek] Dvě rovnice, dvě přímky
> ![[lag01-primky.png]]
> *Modrá: 2x + y = 5, oranžová: x − y = −2. Průsečík [1; 3] je řešení soustavy.*

**Formálně:** najdi x ∈ ℝ, aby ax = b
