# sloupcové vektory

> [!lidsky] Lidsky
> Sloupce n čísel. Nejběžnější lineární prostor; skoro všechno se do něj nakonec převede.
>
> *Příklad:* (1; −2; 0) ∈ ℝ³; (1; −2; 0) + (3; 1; 1) = (4; −1; 1) a 2·(1; −2; 0) = (2; −4; 0).

**Formálně:** 𝔽ⁿ = {(x₁; …; xₙ) | xᵢ ∈ 𝔽}
