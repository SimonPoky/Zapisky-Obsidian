# stopa matice

> [!lidsky] Lidsky
> Součet čísel na hlavní diagonále čtvercové matice. Matice se stopou 0 tvoří podprostor, protože stopa součtu je součet stop a stopa násobku je násobek stopy.
>
> *Příklad:* tr $\begin{pmatrix}1&2\\3&4\end{pmatrix}$ = 1 + 4 = 5. Matice $\begin{pmatrix}2&7\\0&-2\end{pmatrix}$ má stopu 0, patří tedy do podprostoru matic se stopou 0.

**Formálně:** tr A = a₁₁ + a₂₂ + … + aₙₙ; tr(A + B) = tr A + tr B, tr(αA) = α tr A
