# lineární rekurentní rovnice

> [!lidsky] Lidsky
> Recept, který další člen posloupnosti spočítá jako lineární kombinaci předchozích. Řešení tvoří podprostor posloupností; u rekurence druhého řádu má dimenzi 2, protože řešení je určené prvními dvěma členy.
>
> *Příklad:* a_{n+2} = a_{n+1} + aₙ s a₀ = 0, a₁ = 1 dává Fibonacciho čísla 0, 1, 1, 2, 3, 5, 8, …; (1, 1, 1, …) řešením není, protože 1 − 1 − 1 ≠ 0.

**Formálně:** Pro F: ℝ^{ℕ₀} → ℝ^{ℕ₀}, (aₙ) ↦ (a_{n+2} − a_{n+1} − aₙ) je rovnice a_{n+2} = a_{n+1} + aₙ rovnost F(aₙ) = 0; množina řešení je ker F, lineární podprostor dimenze 2 s bází ((φ₊ⁿ), (φ₋ⁿ))
