# součet lineárních zobrazení

> [!lidsky] Lidsky
> Zobrazení se sčítají bod po bodu: do obou dosadíš stejný vektor a výsledky sečteš, stejně jako u funkcí (f + g)(t) = f(t) + g(t).
>
> *Příklad:* A(x; y) = (x + y; 2y), B(x; y) = (y; x − y) ⇒ (A + B)(x; y) = (x + 2y; x + y); (A + B)(1; 2) = (5; 3) = (3; 4) + (2; −1).

**Formálně:** Buďte V, W lineární prostory nad 𝔽, A, B ∈ Lin(V, W). Součet A + B: V → W je dán předpisem (A + B)(x) = Ax + Bx; je opět lineární a [A + B]^{𝒳→𝒴} = [A]^{𝒳→𝒴} + [B]^{𝒳→𝒴}
