# skalární násobek lineárního zobrazení

> [!lidsky] Lidsky
> Zobrazení vynásobené číslem α: nejdřív zobraz, výsledek vynásob α. Matice se vynásobí α celá.
>
> *Příklad:* pro A(x; y) = (x + y; 2y) je (3A)(x; y) = (3x + 3y; 6y), třeba (3A)(1; 2) = 3·(3; 4) = (9; 12).

**Formálně:** Buďte V, W lineární prostory nad 𝔽, A ∈ Lin(V, W), α ∈ 𝔽. Skalární násobek αA: V → W je dán předpisem (αA)(x) = α(Ax); je opět lineární a [αA]^{𝒳→𝒴} = α[A]^{𝒳→𝒴}
