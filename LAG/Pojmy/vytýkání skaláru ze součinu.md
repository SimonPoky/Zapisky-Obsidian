# vytýkání skaláru ze součinu

> [!lidsky] Lidsky
> Číslo smíš ze součinu vytknout dopředu, ať stojí u kteréhokoli činitele. U matic to ušetří práci se zlomky a odmocninami.
>
> *Příklad:* pro A = $\begin{pmatrix}1&0\\1&1\end{pmatrix}$ a B = $\begin{pmatrix}2&1\\0&1\end{pmatrix}$ je AB = $\begin{pmatrix}2&1\\2&2\end{pmatrix}$, takže (3A)B = 3(AB) = A(3B) = $\begin{pmatrix}6&3\\6&6\end{pmatrix}$. Podobně (√2/2·A)(√2·E) = (√2/2·√2)·A = A.

**Formálně:** Buďte U, V, W lineární prostory nad 𝔽, A ∈ Lin(V, W), B ∈ Lin(U, V), α ∈ 𝔽 ⇒ (αA)B = α(AB) = A(αB); totéž pro matice A ∈ 𝔽^{l×m}, B ∈ 𝔽^{m×n}
