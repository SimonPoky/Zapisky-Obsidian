# vlastní vektor

> [!lidsky] Lidsky
> Nenulový vektor, který operátor neotočí, jen ho vynásobí číslem: Ax = λx. Leží na přímce, která se zobrazí sama na sebe.
>
> *Příklad:* (1; 1) je vlastní vektor A = (3 0; 1 2) k λ = 3, protože A(1; 1) = (3; 3); také (2; 2) nebo (−1; −1). (1; 0) vlastní není: A(1; 0) = (3; 1) míří jinam.

**Formálně:** Buď L lineární prostor nad 𝔽, A ∈ Lin(L), λ ∈ 𝔽. Vektor x ∈ L, x ≠ 0, s Ax = λx se nazývá vlastní vektor příslušný vlastnímu číslu λ
