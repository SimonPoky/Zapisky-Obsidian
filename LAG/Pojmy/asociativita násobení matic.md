# asociativita násobení matic

> [!lidsky] Lidsky
> U součinu více matic nezáleží na tom, kterou dvojici vynásobíš dřív, takže závorky se nepíšou: ABC. Pořadí matic ale měnit nesmíš.
>
> *Příklad:* A = $\begin{pmatrix}1&2\\0&1\end{pmatrix}$, B = $\begin{pmatrix}0&1\\1&1\end{pmatrix}$, v = (2; 1): (AB)v = $\begin{pmatrix}2&3\\1&1\end{pmatrix}$(2; 1) = (7; 3) a A(Bv) = A(1; 3) = (7; 3).

**Formálně:** Buď 𝔽 číselné těleso, A ∈ 𝔽^{k×l}, B ∈ 𝔽^{l×m}, C ∈ 𝔽^{m×n} ⇒ (AB)C = A(BC); prvek (i, j) obou stran je Σₓ Σᵧ a_{iy} b_{yx} c_{xj}
