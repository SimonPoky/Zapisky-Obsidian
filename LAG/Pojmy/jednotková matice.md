# jednotková matice

> [!lidsky] Lidsky
> Maticová jednička: jedničky na diagonále, jinde nuly. Jako zobrazení nechá každý vektor na místě; je to matice identity v libovolné bázi.
>
> *Příklad:* E₂ = $\begin{pmatrix}1&0\\0&1\end{pmatrix}$ a E₂(5; −2) = (5; −2). Matice $\begin{pmatrix}1&1\\0&1\end{pmatrix}$ jednotková není: (0; 1) pošle na (1; 1).

**Formálně:** Matici Eₙ ∈ 𝔽^{n×n} s prvky [Eₙ]ᵢⱼ = δᵢⱼ (1 pro i = j, 0 pro i ≠ j) nazýváme jednotková matice. Pro každou bázi 𝒳 prostoru V dimenze n je [id]^{𝒳→𝒳} = Eₙ
