# kanonická báze

> [!lidsky] Lidsky
> Nejpohodlnější báze 𝔽ⁿ: vektor eᵢ má jedničku na i-tém místě a jinde nuly. Souřadnice vektoru v ní jsou prostě jeho složky: (x; y) = x·(1; 0) + y·(0; 1).

**Formálně:** 𝓔 = (e₁, …, eₙ), [eᵢ]ⱼ = 1 pro j = i, jinak 0
