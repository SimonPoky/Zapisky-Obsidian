# transpozice součinu matic

> [!lidsky] Lidsky
> Transpozice součinu otočí pořadí činitelů, jako když se svléká: co se oblékne poslední, sundá se první. A^T B^T by často ani neměl správné rozměry.
>
> *Příklad:* A = (1 2; 0 1), B = (1 0; 3 1): (AB)ᵀ = (7 3; 2 1) = BᵀAᵀ, ale AᵀBᵀ = (1 3; 2 7).

**Formálně:** A ∈ 𝔽^{m×n}, B ∈ 𝔽^{n×p} ⇒ (AB)ᵀ = BᵀAᵀ ∈ 𝔽^{p×m}
