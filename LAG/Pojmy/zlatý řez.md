# zlatý řez

> [!lidsky] Lidsky
> Číslo φ₊ = (1 + √5)/2 ≈ 1,618, jediné kladné číslo, jehož druhá mocnina je o 1 větší než ono samo. Je to limita podílů sousedních Fibonacciho čísel.
>
> *Příklad:* φ₊² = (3 + √5)/2 ≈ 2,618 = φ₊ + 1; 13/8 = 1,625 a 89/55 ≈ 1,6182 se blíží φ₊.

**Formálně:** φ± = (1 ± √5)/2 jsou kořeny λ² − λ − 1 = 0, tedy φ±² = φ± + 1; zlatý řez je φ₊ ≈ 1,618 (φ₋ ≈ −0,618)
