# operátor derivace

> [!lidsky] Lidsky
> Derivace jako lineární operátor na polynomech: xᵏ přejde na k·xᵏ⁻¹. V bázi (1, x, x²) má matici s čísly 1, 2 nad diagonálou.

**Formálně:** D: ℝ^{≤n}[x] → ℝ^{≤n}[x], D(α₀ + α₁x + … + αₙxⁿ) = α₁ + 2α₂x + … + nαₙxⁿ⁻¹; je lineární; pro n = 2 a 𝓔 = (1, x, x²) je [D]^𝓔 = (0 1 0; 0 0 2; 0 0 0)
