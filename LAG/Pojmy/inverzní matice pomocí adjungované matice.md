# inverzní matice pomocí adjungované matice

> [!lidsky] Lidsky
> Inverzi jde napsat vzorcem: adjungovaná matice vydělená determinantem. Pro 2 × 2 je to známé (d −b; −c a)/(ad − bc), pro větší matice je eliminace rychlejší.
>
> *Příklad:* C = (1 2 0; 0 1 1; 1 0 1), det C = 3, C⁻¹ = (1/3)(1 −2 2; 1 1 −1; −1 2 1).

**Formálně:** A ∈ 𝔽ⁿˣⁿ regulární ⇒ A⁻¹ = (1/det A) · adj A; důvod: adj(A) · A = (det A) E
