# adjungovaná matice

> [!lidsky] Lidsky
> Matice algebraických doplňků, ale transponovaná: na místě (i, j) stojí doplněk prvku z místa (j, i). Vydělená determinantem dá inverzní matici.
>
> *Příklad:* adj(a b; c d) = (d −b; −c a), např. adj(3 1; 1 2) = (2 −1; −1 3). Pro C = (1 2 0; 0 1 1; 1 0 1) je adj C = (1 −2 2; 1 1 −1; −1 2 1).

**Formálně:** Buď A ∈ 𝔽ⁿˣⁿ. Adjungovaná matice k A je adj A ∈ 𝔽ⁿˣⁿ, která má na pozici (i, j) algebraický doplněk pozice (j, i) v matici A: [adj A]ᵢⱼ = Dⱼᵢ = (−1)^{i+j} det A^{(j,i)}
