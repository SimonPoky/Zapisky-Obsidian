# homogenní soustava

> [!lidsky] Lidsky
> Soustava lineárních rovnic, která má napravo samé nuly. Její řešení tvoří podprostor: součet i násobek řešení je zase řešení. Nehomogenní soustava podprostor netvoří, nesplňuje ji ani nulový vektor.
>
> *Příklad:* x + y = 0 má řešení t·(1; −1), tedy přímku přes počátek, a ta je podprostor ℝ². Nehomogenní x + y = 1 nesplňuje ani (0; 0), její řešení podprostor netvoří.

**Formálně:** A·x = 0; množina řešení {x ∈ 𝔽ⁿ | A·x = 0} ≤ 𝔽ⁿ
