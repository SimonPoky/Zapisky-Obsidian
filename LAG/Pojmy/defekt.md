# defekt

> [!lidsky] Lidsky
> Kolik směrů zobrazení „zabije“: dimenze jádra. Defekt 0 znamená prosté zobrazení.
>
> *Příklad:* A = $\begin{pmatrix}0&2&1\\0&4&2\end{pmatrix}$ má ker A = span{(1; 0; 0), (0; 1; −2)} se dvěma LN generátory, tedy def A = 2. Otočení roviny má defekt 0.

> [!obrazek] Hodnost + defekt = dimenze vstupu
> ![[lag11-dimenze.png]]
> *Oranžová část je hodnost (přežije), zelená defekt (zabije se); dohromady vždy dají dimenzi definičního oboru $V$. Otočení nezabije nic, nulové zobrazení všechno.*

**Formálně:** Buďte V a W lineární prostory nad 𝔽, A ∈ Lin(V, W). Defekt lineárního zobrazení A je číslo def A = dim ker A
