# Cramerovo pravidlo

> [!lidsky] Lidsky
> Každou neznámou regulární soustavy dostaneš jako podíl dvou determinantů: v čitateli matice, ve které je místo sloupce té neznámé pravá strana, ve jmenovateli původní matice.
>
> *Příklad:* 2x + y = 5, x + 3y = 10: det A = 5, x = det(5 1; 10 3)/5 = 1, y = det(2 5; 1 10)/5 = 3.

**Formálně:** A ∈ 𝔽ⁿˣⁿ regulární, b⃗ ∈ 𝔽ⁿ, A^{(i)} = A s i-tým sloupcem nahrazeným b⃗ ⇒ jediné řešení Ax⃗ = b⃗ má složky xᵢ = det A^{(i)} / det A, i = 1, …, n
