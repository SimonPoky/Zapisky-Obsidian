# axiomy lineárního prostoru

> [!lidsky] Lidsky
> 8 pravidel počítání, která se nedokazují, ale požadují. Říkají, že se sčítáním a násobením vektorů zacházíš jako u čísel.
>
> *Příklad:* v ℝ² platí třeba distributivita 2·((1; 0) + (0; 3)) = 2·(1; 0) + 2·(0; 3) = (2; 6) a 1·(4; −1) = (4; −1). Kdyby se násobilo α ⊙ (a; b) = (αa; 0), padl by axiom 1·x = x: 1 ⊙ (4; −1) = (4; 0).

**Formálně:** komutativita, asociativita, 0, −x, α(βx) = (αβ)x, 1x = x, 2× distributivita
