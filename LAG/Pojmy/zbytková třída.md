# zbytková třída

> [!lidsky] Lidsky
> Všechna celá čísla, která mají po dělení n stejný zbytek, v jednom „pytli“. Třídu zapíšeš libovolným jejím prvkem: [2] = [14] = [−10] pro n = 12.
>
> *Příklad:* pro n = 12 je [2] = {…, −22, −10, 2, 14, 26, …} a [0] = 12ℤ.

**Formálně:** Zafixujme n ∈ ℕ. Pro i ∈ ℤ je zbytková třída [i] = {i + kn | k ∈ ℤ} = {…, i − n, i, i + n, i + 2n, …}; různých tříd je n: [0], [1], …, [n − 1]
