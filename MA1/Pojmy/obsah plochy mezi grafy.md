# obsah plochy mezi grafy

> [!lidsky] Lidsky
> Plocha mezi dvěma křivkami je plocha pod horní minus plocha pod dolní, tedy integrál rozdílu. Musíš vědět, která je nahoře; kde se kříží, interval rozdělíš.
>
> *Příklad:* x + 2 a x² se protínají v −1 a 2, přímka je nahoře: ∫₋₁² (x + 2 − x²) dx = 9/2.

**Formálně:** f, g spojité na [a; b], f ≥ g na [a; b] ⇒ obsah plochy mezi grafy je A(f, g) = ∫ₐᵇ (f − g); z obecné věty s ⋆ = −, A = min, B = max, C = max, D = min
