# lineární aproximace

> [!lidsky] Lidsky
> Nahrazení funkce její tečnou blízko bodu p. Chyba je zanedbatelná i vůči vzdálenosti x − p.

**Formálně:** f′(p) existuje, T₁(f, p)(x) = f(p) + f′(p)(x − p) ⇒ lim_{x→p} (f(x) − T₁(f, p)(x))/(x − p) = 0
