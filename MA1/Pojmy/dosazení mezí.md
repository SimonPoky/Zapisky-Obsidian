# dosazení mezí

> [!lidsky] Lidsky
> Zkratka „dosaď horní mez, dosaď dolní mez, odečti“; díky ní se výpočet integrálu vejde na jeden řádek.
>
> *Příklad:* [t³/3]₁₀¹⁵ = 3375/3 − 1000/3 = 2375/3; [sin t]₀^π = 0 − 0 = 0.
