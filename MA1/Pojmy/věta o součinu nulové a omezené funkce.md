# věta o součinu nulové a omezené funkce

> [!lidsky] Lidsky
> Co jde k nule, vynásobené něčím omezeným, jde taky k nule. Proto x · sin(1/x) → 0 pro x → 0, i když sin(1/x) limitu nemá. Omezenost je nutná: x · (1/x) = 1.

**Formálně:** lim_𝒮 f = 0 ∧ |g| ≤𝒮 c ⇒ lim_𝒮 (f · g) = 0
