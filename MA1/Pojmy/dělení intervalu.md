# dělení intervalu

> [!lidsky] Lidsky
> Rozřezání intervalu na menší kousky body a = x₀ < x₁ < … < xₙ = b. Jemnější dělení obsahuje všechny body původního a možná další.
>
> *Příklad:* 0 < 1 < 2 je dělení [0; 2] na dva kousky; 0 < 0,5 < 1 < 1,5 < 2 je jemnější (čtyři kousky).

**Formálně:** dělení Δ intervalu [a; b] jsou body a = x₀ < x₁ < … < xₙ₋₁ < xₙ = b; Δ′ je jemnější než Δ, obsahuje-li všechny body Δ
