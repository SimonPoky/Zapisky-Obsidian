# celá čísla

> [!lidsky] Lidsky
> …, −2, −1, 0, 1, 2, … postavená z ℕ. Záporné číslo je „dluh“: dvojice (m, n) znamená rozdíl m − n, takže (5, 8) i (0, 3) jsou totéž číslo −3.

**Formálně:** −3 = {(n, n + 3) | n ∈ ℕ}; (m, n) ~ (m′, n′) ⇔ m + n′ = m′ + n
