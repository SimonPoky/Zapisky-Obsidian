# konvergentní integrál

> [!lidsky] Lidsky
> Konverguje = nevlastní integrál vyšel jako konečné reálné číslo. Diverguje = vyšlo +∞ nebo −∞, nebo integrál vůbec neexistuje.
>
> *Příklad:* ∫₁^{+∞} dt/t² = 1 konverguje; ∫₁^{+∞} dt/t = +∞ diverguje; ∫ od −1/π do 0 z (1/t²)cos(1/t) neexistuje, také diverguje.

**Formálně:** ∫ₐᵇ f (ve smyslu nevlastního integrálu) konverguje ⟺ ∫ₐᵇ f ∈ ℝ; diverguje ⟺ ∫ₐᵇ f = ±∞ nebo ∫ₐᵇ f neexistuje
