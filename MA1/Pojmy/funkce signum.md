# funkce signum

> [!lidsky] Lidsky
> Funkce, která vrátí jen znaménko čísla: −1 pro záporná, 0 pro nulu, 1 pro kladná. V nule má skok, proto je příklad funkce, která má integrál, ale nemá primitivní funkci.
>
> *Příklad:* signum(−3,7) = −1, signum(0) = 0, signum(π) = 1; ∫₋₁¹ signum = −1 + 1 = 0.

**Formálně:** signum(x) = −1 pro x < 0, 0 pro x = 0, 1 pro x > 0
