# fundamentální věta kalkulu

> [!lidsky] Lidsky
> Shrnutí: integrál spojité funkce existuje, jeho derivace podle horní meze je f a počítá se jako rozdíl hodnot libovolné primitivní funkce.
>
> *Příklad:* ∫₀² 3x² dx = [x³]₀² = 8 − 0 = 8; s primitivní x³ + 3 vyjde (8 + 3) − (0 + 3) = 8 taky.

**Formálně:** f spojitá na [a; b] ⇒ (1) ∫ₐˣ f(t) dt existuje pro všechna x ∈ [a; b]; (2) d/dx ∫ₐˣ f(t) dt = f(x); (3) ∫ₐˣ f(t) dt = F(x) − F(a) pro libovolnou primitivní F k f
