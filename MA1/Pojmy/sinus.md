# sinus

> [!lidsky] Lidsky
> Výška bodu na jednotkové kružnici nad místem cos x; z Pythagorovy věty √(1 − cos² x). Takto definovaný jen pro x ∈ [0; π], kde je nezáporný.
>
> *Příklad:* sin(π/2) = √(1 − 0) = 1; sin(2π/3) = √(1 − ¼) = √3/2 ≈ 0,866.

**Formálně:** 0 ≤ x ≤ π: sin x = √(1 − cos² x)
