# exponenciální rozdělení

> [!lidsky] Lidsky
> Model doby čekání na událost „bez paměti“: krátké čekání je nejčastější, dlouhé čím dál vzácnější; λ je průměrný počet událostí za jednotku času.
>
> *Příklad:* λ = 2: hustota 2e^{−2t} pro t ≥ 0, E(X) = 1/λ = ½, P(1 ≤ X ≤ 2) = e^{−2} − e^{−4} ≈ 0,117.

**Formálně:** λ > 0: hustota f(x) = 0 pro x < 0, f(x) = λe^{−λx} pro x ≥ 0; E(X) = 1/λ (per partes)
