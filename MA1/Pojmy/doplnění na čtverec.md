# doplnění na čtverec

> [!lidsky] Lidsky
> Kvadratický výraz přepíšeš na (t + něco)² + konstanta. U jmenovatele bez reálných kořenů je konstanta kladná a substitucí vznikne tabulkový integrál s arctan (nebo argsinh pod odmocninou).
>
> *Příklad:* t² + 2t + 2 = (t + 1)² + 1, takže ∫₀¹ dt/(t² + 2t + 2) = ∫₁² dz/(z² + 1) = arctan 2 − π/4.

**Formálně:** t² + pt + q = (t + p/2)² + (q − p²/4); pro p² − 4q < 0 je q − p²/4 > 0
