# ireducibilní polynom

> [!lidsky] Lidsky
> Obdoba prvočísla mezi polynomy: nejde napsat jako součin dvou reálných polynomů menšího stupně, jen vytknout konstantu.
>
> *Příklad:* t − 3 a t² + 1 jsou ireducibilní v ℝ[x]; t² + 2t − 3 = (t + 3)(t − 1) ne; x⁴ + 4 = (x² − 2x + 2)(x² + 2x + 2) ne, i když nemá reálné kořeny.

**Formálně:** a ∈ ℝ[x], deg a ≥ 1, je ireducibilní ⟺ z a = a₁ · a₂ (a₁, a₂ ∈ ℝ[x]) plyne deg a₁ = 0 nebo deg a₂ = 0
