# neklesající posloupnost

> [!lidsky] Lidsky
> Posloupnost, jejíž členy se nikdy nezmenšují. Vždy má limitu v ℝ*, a to své supremum (případně +∞).

**Formálně:** aₙ ≤ aₙ₊₁ pro všechna n ⇒ lim aₙ = sup{aₙ | n ≥ n₀}
