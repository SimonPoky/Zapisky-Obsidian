# jednostranná limita

> [!lidsky] Lidsky
> Limita ve směru x → p⁻ (jen zleva) nebo x → p⁺ (jen zprava). Oboustranná limita existuje, právě když se obě jednostranné shodují.
>
> *Příklad:* pro f(x) = |x|/x je lim_{x→0⁻} f = −1 a lim_{x→0⁺} f = 1. Jednostranné limity se liší, takže oboustranná limita v 0 neexistuje.

**Formálně:** lim_{x→p} f = L ⇔ lim_{x→p⁻} f = L = lim_{x→p⁺} f
