# primitivní funkce s předepsanou hodnotou

> [!lidsky] Lidsky
> Předepíšeš-li bod, kterým má graf primitivní funkce projít, zbude jich právě jedna. Hodí se u diferenciálních rovnic.
>
> *Příklad:* k 2x s G(1) = 5: z x² + c a 1 + c = 5 je c = 4, G(x) = x² + 4, a jiná taková není.

**Formálně:** f spojitá na [a; b], F primitivní k f, x₀ ∈ [a; b], y₀ ∈ ℝ ⇒ existuje právě jedna primitivní funkce G k f s G(x₀) = y₀, a to G(x) = F(x) + (y₀ − F(x₀))
