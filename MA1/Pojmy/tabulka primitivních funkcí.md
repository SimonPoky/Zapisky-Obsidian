# tabulka primitivních funkcí

> [!lidsky] Lidsky
> Tabulka derivací přečtená pozpátku: ke každé známé derivaci patří jeden řádek tabulky integrálů. Platí jen tam, kde je integrand na celém [a; b] spojitý.
>
> *Příklad:* ∫₀¹ 1/(1 + t²) dt = arctan 1 − arctan 0 = π/4; ∫₁ᵉ 1/t dt = 1; ∫₋₁¹ 1/t² dt tabulkou spočítat nejde (v 0 není spojitá).

**Formálně:** ∫ₐᵇ tⁿ dt = (bⁿ⁺¹ − aⁿ⁺¹)/(n + 1) pro n ≠ −1; ∫ₐᵇ 1/t dt = ln(b/a) pro a, b > 0; ∫ₐᵇ eᵗ dt = eᵇ − eᵃ; ∫ₐᵇ sin t dt = −cos b + cos a; ∫ₐᵇ cos t dt = sin b − sin a; ∫ₐᵇ 1/√(1 − t²) dt = arcsin b − arcsin a pro a, b ∈ (−1; 1); ∫ₐᵇ 1/(1 + t²) dt = arctan b − arctan a
