# rekurzivní definice

> [!lidsky] Lidsky
> Pravidlo, jak spočítat úlohu pomocí o krok menší úlohy, plus kotva, kde se zastavit. Sčítání je opakované succ, násobení opakované přičítání.

**Formálně:** m + 0 = m, m + succ(k) = succ(m + k); m · 0 = 0, m · succ(k) = m · k + m
