# neurčitý výraz

> [!lidsky] Lidsky
> Kombinace jako 0/0, ∞/∞, 0·∞ nebo 1^∞, u které z limit jednotlivých částí nepoznáš výsledek. Musí se počítat dál, často l'Hospitalem po úpravě.
>
> *Příklad:* x/x, x²/x i x/x² jsou pro x → 0⁺ všechny typu 0/0, ale limity jsou 1, 0 a +∞. Proto 0/0 nemá jednu hodnotu.

> [!obrazek] Typ ∞/∞ může dát cokoli
> ![[ma105-nekonecno.png]]
> *Čtyři podíly, u kterých čitatel i jmenovatel jdou k +∞. Modrá x/x je stále 1, zelená 3x/x stále 3, oranžová x²/x = x roste do nekonečna a červená čárkovaná x/x² = 1/x klesá k nule.*

**Formálně:** 0/0, (±∞)/(±∞), 0·(±∞), (+∞) − (+∞), 1^(±∞), 0⁰, (+∞)⁰: aritmetika limit je v ℝ* nedefinuje; typ ?/|±∞| = |jmenovatel| → +∞, o čitateli nic
