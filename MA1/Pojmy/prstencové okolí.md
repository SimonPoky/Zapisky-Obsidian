# prstencové okolí

> [!lidsky] Lidsky
> Okolí bodu p s vyjmutým bodem p. Kusy směru x → p; hodnota v samotném p limitu neovlivní.

**Formálně:** Pδ(p) = (p − δ; p) ∪ (p; p + δ) = {x | 0 < |x − p| < δ}
