# kosinus

> [!lidsky] Lidsky
> Místo na ose x, kde musíš výseč jednotkového kruhu říznout, aby měla plochu x/2, tedy aby oblouk měřil x.
>
> *Příklad:* cos(π/2) = 0, protože P(0) = π/4; cos π = −1, protože P(−1) = π/2; cos(2π/3) = −½, protože P(−½) = π/3.

**Formálně:** 0 ≤ x ≤ π: cos x = to jediné z ∈ [−1; 1], pro které P(z) = x/2
