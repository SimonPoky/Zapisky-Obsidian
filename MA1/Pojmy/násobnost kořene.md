# násobnost kořene

> [!lidsky] Lidsky
> Kolikrát lze z polynomu vytknout závorku (x − p). Jednoduchý kořen graf osy x protne, dvojnásobný se jí jen dotkne.
>
> *Příklad:* x³ − 3x + 2 = (x − 1)²(x + 2): 1 je dvojnásobný kořen (a*(x) = x + 2, a*(1) = 3 ≠ 0), −2 jednoduchý.

**Formálně:** p je k-násobný kořen a ⟺ a(x) = (x − p)ᵏ · a*(x) pro polynom a* s a*(p) ≠ 0
