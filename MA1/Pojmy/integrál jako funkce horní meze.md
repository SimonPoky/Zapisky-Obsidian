# integrál jako funkce horní meze

> [!lidsky] Lidsky
> Funkce, která k x přiřadí plochu (se znaménkem) od a do x: počítadlo nasbírané plochy, na startu 0.
>
> *Příklad:* pro f(t) = cos t a a = 0 je F(x) = sin x: F(0) = 0, F(π/2) = 1, F(π) = 0 (kladná a záporná část se vyruší).

> [!obrazek] Plocha se znaménkem a funkce F
> ![[ma111-horni-mez.png]]
> *Nahoře modrý graf f(t) = cos t; F(x) je zelená plocha nad osou minus červená plocha pod osou od 0 po oranžovou čáru x. Dole oranžový graf F(x) = sin x: roste, kde je f kladná, klesá, kde je záporná, a F(0) = 0.*

**Formálně:** f spojitá na [a; b], F : [a; b] → ℝ, F(x) = ∫ₐˣ f; F(a) = 0 a F(b) − F(a) = ∫ₐᵇ f
