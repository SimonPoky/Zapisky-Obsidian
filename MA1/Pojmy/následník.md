# následník

> [!lidsky] Lidsky
> Další číslo v řadě. Vznikne tak, že k číslu přidáš jeho samotného jako nový prvek.
>
> *Příklad:* 0 = ∅, 1 = {0}, 2 = {0, 1} a succ(2) = 2 ∪ {2} = {0, 1, 2} = 3: trojka má právě tři prvky.

> [!obrazek] Čísla jako množiny
> ![[ma101-vonneumann.png]]
> *Každé číslo je množina všech menších čísel, takže n má přesně n prvků. Šipka succ přidá dosavadní číslo jako nový prvek.*

**Formálně:** succ(n) = n ∪ {n} = {0, …, n}, tj. n + 1
