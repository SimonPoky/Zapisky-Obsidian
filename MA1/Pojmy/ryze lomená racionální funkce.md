# ryze lomená racionální funkce

> [!lidsky] Lidsky
> Racionální funkce, kde má čitatel menší stupeň než jmenovatel, obdoba „pravého zlomku“ 2/3. Jen ji jde rovnou rozložit na parciální zlomky.
>
> *Příklad:* (4t + 8)/(t² + 2t − 3) je ryze lomená (1 < 2); (t² + 1)/t ryze lomená není, dělením (t² + 1)/t = t + 1/t.

**Formálně:** a(x)/b(x) je ryze lomená ⟺ deg a < deg b
