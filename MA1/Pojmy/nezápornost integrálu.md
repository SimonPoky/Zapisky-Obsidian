# nezápornost integrálu

> [!lidsky] Lidsky
> Integrál funkce, která je všude nad osou (nebo na ní), nemůže vyjít záporný. Plyne z omezenosti.
>
> *Příklad:* x² ≥ 0 na [−1; 1], a opravdu ∫₋₁¹ x² = 2/3 ≥ 0. Pro f(x) = x na [−1; 1] (mění znaménko) vyjde ∫ = 0 a obecně se nic neví.

**Formálně:** f spojitá na [a; b], 0 ≤ f na [a; b] ⇒ 0 ≤ ∫ₐᵇ f; navíc z aditivity ∫ₐᵃ f = 0
