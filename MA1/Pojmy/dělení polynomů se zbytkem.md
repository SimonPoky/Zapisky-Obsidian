# dělení polynomů se zbytkem

> [!lidsky] Lidsky
> Jako 17 : 5 = 3 zbytek 2: polynom vydělíš polynomem a zbude zbytek nižšího stupně než dělitel. Racionální funkce = polynom + ryze lomená funkce.
>
> *Příklad:* x³ + 2x² − x + 3 = (x² + 3x + 2)(x − 1) + 5, tedy podíl x² + 3x + 2 a zbytek 5.

**Formálně:** a, b polynomy, b ≠ 0 ⇒ existují právě jedny polynomy q, r s a = q·b + r a deg r < deg b (nebo r = 0); tedy a/b = q + r/b
