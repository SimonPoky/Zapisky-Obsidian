# přirozený logaritmus

> [!lidsky] Lidsky
> Plocha pod hyperbolou 1/t od 1 do x; pro 0 < x < 1 se počítá se záporným znaménkem (meze pozpátku).
>
> *Příklad:* ln 1 = 0, ln 2 = ∫₁² dt/t ≈ 0,693 (mezi ½ a 1 z omezenosti integrálu), ln ½ ≈ −0,693. ln 0 ani ln(−1) definovaný není.

**Formálně:** x > 0: ln x = ∫₁ˣ (1/t) dt
