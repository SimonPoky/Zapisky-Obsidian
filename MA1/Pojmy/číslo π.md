# číslo π

> [!lidsky] Lidsky
> Dvojnásobek plochy pod horní půlkružnicí √(1 − t²), tedy plocha jednotkového kruhu. Zavedené jen integrálem, bez geometrie úhlů.
>
> *Příklad:* 2∫₋₁¹ √(1 − t²) dt ≈ 3,14159; hrubý odhad z omezenosti integrálu: 0 ≤ π ≤ 4. Je to i délka půlkružnice ∫₋₁¹ dt/√(1 − t²).

**Formálně:** π = 2 · ∫₋₁¹ √(1 − t²) dt
