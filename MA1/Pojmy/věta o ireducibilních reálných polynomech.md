# věta o ireducibilních reálných polynomech

> [!lidsky] Lidsky
> Nad ℝ jsou nerozložitelné jen lineární polynomy a kvadratické se záporným diskriminantem, protože komplexní kořeny chodí v párech z, z̄. Každý reálný polynom je součin takových kusů.
>
> *Příklad:* t³ − 2t² + 4t − 8 = (t − 2)(t² + 4), kde t² + 4 má D = −16 < 0.

**Formálně:** ireducibilní polynomy v ℝ[x] mají stupeň 1 nebo 2; ax² + bx + c je ireducibilní ⟺ b² − 4ac < 0; každý a ∈ ℝ[x] = c · ∏(x − pᵢ)^{kᵢ} · ∏(x² + pⱼx + qⱼ)^{mⱼ} s pⱼ² − 4qⱼ < 0
