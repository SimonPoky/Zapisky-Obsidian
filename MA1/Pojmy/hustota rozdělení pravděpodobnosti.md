# hustota rozdělení pravděpodobnosti

> [!lidsky] Lidsky
> Funkce, ze které se pravděpodobnost počítá jako plocha: P(a ≤ X ≤ b) je plocha pod f nad [a; b]. Celková plocha je 1.
>
> *Příklad:* f(x) = 3x² na [0; 1], jinde 0: ∫₀¹ 3x² = 1, je to hustota. Nepříklad: f = 2 na [0; 1] (celková plocha 2).

**Formálně:** f definovaná na ℝ, f ≥ 0, ∫_{−∞}^{+∞} f = 1, a Prob(a ≤ X ≤ b) = ∫ₐᵇ f(t) dt
