# pozitivní kužel

> [!lidsky] Lidsky
> Množina kladných čísel, ze které se vyrobí uspořádání: r < s znamená, že s − r je kladné. Musí být dána dřív než nerovnost, jinak je definice v kruhu.

**Formálně:** ℝ = −ℝ⁺ ∪ {0} ∪ ℝ⁺ (disjunktně); r, s ∈ ℝ⁺ ⇒ r + s, r·s ∈ ℝ⁺; r < s ⇔ s − r ∈ ℝ⁺
