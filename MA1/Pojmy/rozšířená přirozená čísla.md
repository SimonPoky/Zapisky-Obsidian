# rozšířená přirozená čísla

> [!lidsky] Lidsky
> ℕ s přidaným umělým stropem +∞, aby každá množina měla supremum (sup ℕ = +∞). 0 · ∞ se nedefinuje.

**Formálně:** ℕ* = {0, 1, 2, …} ∪ {+∞}; n + ∞ = ∞; n · ∞ = ∞ pro n ≠ 0; +∞ = ℕ jako množina
