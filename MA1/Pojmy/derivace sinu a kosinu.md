# derivace sinu a kosinu

> [!lidsky] Lidsky
> Kosinus je inverze ke Q = 2P, takže jeho derivace je převrácená hodnota Q′; vzorce z tabulky tak plynou jen z definice π a integrálu.
>
> *Příklad:* (cos)′(π/2) = −sin(π/2) = −1 a Q′(0) = −1, převrácená hodnota sedí; (cos)′(2π/3) = −√3/2 ≈ −0,866.

**Formálně:** 0 < x < π ⇒ (cos x)′ = −sin x a (sin x)′ = cos x; důkaz: cos = Q⁻¹ pro Q = 2P, Q′(z) = −1/√(1 − z²), (cos x)′ = 1/Q′(cos x) = −√(1 − cos² x)
