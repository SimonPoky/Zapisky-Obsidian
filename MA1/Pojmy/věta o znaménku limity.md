# věta o znaménku limity

> [!lidsky] Lidsky
> Kladná limita znamená, že funkce je blízko cíle kladná. Naopak z f ≥ 0 plyne jen L ≥ 0: ostrá nerovnost se do limity nepřenáší (1/x > 0, ale limita pro x → +∞ je 0).

**Formálně:** lim_𝒮 f = L: lim(−f) = −L; L > 0 ⇒ f >𝒮 0; f ≥𝒮 0 ⇒ L ≥ 0 (a zrcadlově)
