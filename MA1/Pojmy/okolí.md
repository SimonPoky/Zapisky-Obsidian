# okolí

> [!lidsky] Lidsky
> Terč kolem cíle L: interval (L − ε; L + ε). U +∞ je to (ε; +∞], takže velké ε znamená malý terč. Průnik všech okolí je jen {L}.

> [!obrazek] Okolí a směry
> ![[ma103-okoli.png]]
> *Nahoře okolí cíle: oranžově [−∞; −ε), modře (L − ε; L + ε), zeleně (ε; +∞]. Dole kusy směrů: modře x → p (bez bodu p, prázdné kolečko), oranžově x → p⁺, zeleně x → +∞.*

**Formálně:** Uε(L) = (L − ε; L + ε) pro L ∈ ℝ, (ε; +∞] pro +∞, [−∞; −ε) pro −∞; 𝒩(L) = {Uε(L) | ε > 0}
