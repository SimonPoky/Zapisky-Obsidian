# rozklad na parciální zlomky

> [!lidsky] Lidsky
> Opak sčítání zlomků: ryze lomenou funkci rozložíš na součet parciálních zlomků, protože ty umíš zintegrovat substitucí.
>
> *Příklad:* (4t + 8)/((t + 3)(t − 1)) = 1/(t + 3) + 3/(t − 1); (t² − 13t + 33)/((t − 3)²(t − 4)) = 4/(t − 3) − 3/(t − 3)² − 3/(t − 4).

**Formálně:** r/b ryze lomená, b rozložený na ireducibilní činitele ⇒ r/b je součet parciálních zlomků: za (t − p)ᵏ zlomky A₁/(t − p) + … + A_k/(t − p)ᵏ, za (t² + pt + q)ᵐ s p² − 4q < 0 zlomky (B₁t + C₁)/(t² + pt + q) + … + (B_m t + C_m)/(t² + pt + q)ᵐ; koeficienty jsou určeny jednoznačně
