# spojitá náhodná veličina

> [!lidsky] Lidsky
> Číslo, které vyjde z pokusu a může nabýt hodnot v celém intervalu; pravděpodobnost intervalu je plocha pod hustotou, pravděpodobnost jednoho čísla je 0.
>
> *Příklad:* Čekání na tramvaj jezdící po 10 minutách: hustota 1/10 na [0; 10], P(2 ≤ X ≤ 5) = 0,3, P(X = 3) = 0.

**Formálně:** X je spojitá, existuje-li f definovaná na ℝ (f ≥ 0, ∫_ℝ f = 1) taková, že Prob(a ≤ X ≤ b) = ∫ₐᵇ f(t) dt pro všechna a ≤ b
