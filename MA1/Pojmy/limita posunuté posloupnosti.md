# limita posunuté posloupnosti

> [!lidsky] Lidsky
> Na konečně mnoha prvních členech limitě nezáleží. Když posloupnost začneš číst až od N-tého členu, limita se nezmění.

**Formálně:** N ∈ ℕ pevné: lim_{n→+∞} aₙ = L ⟺ lim_{k→+∞} a_{k+N} = L
