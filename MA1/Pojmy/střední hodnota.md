# střední hodnota

> [!lidsky] Lidsky
> Dlouhodobý průměr výsledků pokusu; geometricky těžiště plochy pod hustotou (celková hmotnost je 1, takže se nedělí).
>
> *Příklad:* Rovnoměrné rozdělení na [1; 3] (hustota ½): E(X) = ∫₁³ t/2 dt = 2. Exponenciální s λ = 2: E(X) = ½.

**Formálně:** X spojitá náhodná veličina s hustotou f: E(X) = ∫_{−∞}^{+∞} t · f(t) dt (první moment hustoty)
