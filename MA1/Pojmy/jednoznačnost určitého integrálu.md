# jednoznačnost určitého integrálu

> [!lidsky] Lidsky
> Dvě přiřazení, která obě splňují aditivitu a omezenost, dávají stejná čísla. Proto je integrál vždy rozdíl hodnot libovolné primitivní funkce.
>
> *Příklad:* ∫₀² x musí být 2: F(x) = ∫₀ˣ t dt je primitivní k x s F(0) = 0, a jediná taková je x²/2, takže F(2) = 2.

**Formálně:** f spojitá na [a; b] ⇒ ∫ₐᵘ f je pro každé u ∈ [a; b] určeno jednoznačně (F(x) = ∫ₐˣ f je jediná primitivní funkce k f s F(a) = 0)
