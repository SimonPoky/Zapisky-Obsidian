# integrál s obrácenými mezemi

> [!lidsky] Lidsky
> Integrál „pozpátku“ (horní mez menší než dolní) je plocha se záporným znaménkem; tak zůstane platit aditivita pro meze v libovolném pořadí.
>
> *Příklad:* ∫₀² x = 2, takže ∫₂⁰ x = −2, a ∫₀² x + ∫₂⁰ x = 0 = ∫₀⁰ x.

**Formálně:** pro a ≤ b definujeme ∫ᵦᵃ f = −∫ₐᵇ f; z aditivity ∫ₐᵃ f = 0
