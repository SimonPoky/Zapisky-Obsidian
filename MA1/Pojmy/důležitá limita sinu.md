# důležitá limita sinu

> [!lidsky] Lidsky
> Podíl sin h / h je směrnice sečny grafu sinu mezi 0 a h, takže jeho limita je derivace sinu v nule, cos 0 = 1. Blízko nuly je sin h ≈ h.
>
> *Příklad:* sin(0,1)/0,1 ≈ 0,9983; sin(0,01)/0,01 ≈ 0,99998.

**Formálně:** lim_{h→0} sin h / h = lim_{h→0} (sin(0 + h) − sin 0)/h = sin′(0) = cos 0 = 1 (bez l'Hospitala, z derivace sinu)
